How the calculations work

TBT = RNT + ABT · Maximum ABT = TBT max − RNT.
TBT max (NDL) is the selected no-decompression time limit at the table depth; it includes RNT. A negative allowance means there is no available no-decompression time; the displayed maximum ABT is capped at zero.

  1. Convert metres to feet (1 ft = 0.3048 m), then round depth up to the next printed row. First dives below 25 ft use 25 ft; repetitive dives below 40 ft use 40 ft because the residual table starts there.
  2. Round ABT up to a whole minute, then use the next group-time cell at or above TBT. Blank cells are skipped.
  3. For the next dive, round the surface interval down to a whole minute and look up the reduced group, then RNT at the next dive’s table depth.
  4. Surface intervals below 10 minutes are unsupported. Only an interval strictly longer than 12 hours clears the previous group under this chart; exactly 12 hours remains repetitive.
  5. If TBT exceeds TBT max, later dives are blocked. Decompression schedules, emergency procedures, ascent limits, altitude, nitrox, flying and gas reserves are outside this calculator.

“Within selected limit” describes the table calculation, not a guarantee against decompression sickness. Follow your instructor’s current procedures and track actual exposure using the same planning method.

Terminology
RNT
Residual nitrogen time for the next depth.
ABT
Actual bottom time entered for this dive.
TBT
Total bottom time used for the table lookup.
TBT max (NDL)
Selected maximum table time without required decompression.
Group
The table letter used to carry residual nitrogen to the next dive.
